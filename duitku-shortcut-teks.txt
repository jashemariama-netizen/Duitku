TEKS UNTUK SHORTCUT DUITKU
==========================

Salin SEMUA teks di antara dua garis "=====" di bawah ini ke dalam satu aksi "Text" di Shortcut.
Setelah ditempel, ganti tiga penanda berikut dengan variabel (tekan penandanya, hapus, lalu pilih variabel dari bar di atas keyboard):

  [BASE64]   -> variabel hasil "Base64 Encode"
  [TANGGAL]  -> variabel tanggal format yyyy-MM-dd
  [JAM]      -> variabel jam format HH:mm

Jangan mengubah tanda kutip atau garis miring terbalik.

===== MULAI =====
{"model":"claude-haiku-5-5","max_tokens":300,"messages":[{"role":"user","content":[{"type":"image","source":{"type":"base64","media_type":"image/jpeg","data":"[BASE64]"}},{"type":"text","text":"Ini screenshot bukti pembayaran atau transfer dari aplikasi bank atau e-wallet di Indonesia. Ambil datanya dan balas HANYA dengan satu baris JSON valid, tanpa markdown dan tanpa teks lain. Kolom: type ('out' untuk uang keluar, 'in' untuk uang masuk), amount (angka bulat rupiah tanpa titik, ambil total yang dibayar), merchant (nama toko atau penerima, singkat), date (YYYY-MM-DD, pakai tanggal di screenshot, jika tidak ada pakai [TANGGAL]), time (HH:mm, pakai jam di screenshot, jika tidak ada pakai [JAM]), src (nama bank atau e-wallet sumber dana, misalnya GoPay, DANA, OVO, ShopeePay, BCA, Mandiri, BRI, BNI, Jago, SeaBank), cat (pilih satu: sarapan, siang, malam, minuman, jajanan, belanja, transport, tagihan, kuliah, kesehatan, hiburan, pacaran, lain). Untuk makanan berat pilih sarapan jika jam 04.00-09.59, siang jika 10.00-15.59, malam jika di luar itu. Minuman seperti kopi atau boba pilih minuman, camilan pilih jajanan. Jika gambar bukan bukti pembayaran, balas {\"error\":\"bukan bukti pembayaran\"}"}]}]}
===== SELESAI =====


ISI HEADER "Get Contents of URL"
--------------------------------
URL            : https://api.anthropic.com/v1/messages
Method         : POST
Header 1       : x-api-key           = (API key kamu dari console.anthropic.com)
Header 2       : anthropic-version   = 2023-06-01
Header 3       : content-type        = application/json
Request Body   : File  (pilih variabel dari aksi "Text" di atas)


CATATAN
-------
- API key tersimpan di Shortcut itu. Jangan membagikan Shortcut-nya ke siapa pun.
- Kalau kamu menambah kategori sendiri di Duitku, tambahkan namanya juga di daftar "cat" pada teks di atas supaya ikut dikenali.
